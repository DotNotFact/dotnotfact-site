# Сайт-визитка Данилы Побединского

Одна страница: что делаю, свои продукты, решения с ценой, как начинаем,
когда я не подхожу. Next.js 16 + TypeScript, собирается в статику.

## Править текст

Весь текст — в `src/content.ts`. Правило: на сайт попадает только то, что
можно подтвердить кодом, снимком или ссылкой. Картинки — `public/work/`.

## Команды

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm lint
pnpm build        # статика в out/
```

## Публикация

`out/` кладётся на любой статический хостинг. Варианты для РФ: GitHub
Pages (как istok-about), Vercel или свой VPS с nginx. Свой домен
(`.ru`) — через регистратора и DNS-запись на хостинг.
